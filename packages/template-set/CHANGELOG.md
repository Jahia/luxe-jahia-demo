# luxe-jahia-demo Changelog

## 1.3.0

### New Features

* Updated the code to showcase usage of `<JImage>` and `getImageProps` from JavaScript Modules 1.3. (#472)

* Added the site's design to forms built with Formidable, on pages and in the Page Builder. (#468)

  Fields, choices, files, steps, buttons and messages now look like the rest of the site. The column a form gets when it is edited on its own in the Page Builder follows once Formidable ships it.

### Bug Fixes

* Added maven.jahia.com to the Maven repositories luxe-jahia-demo uses to download its dependencies.

* Fixed the buttons of forms built with Formidable so they use the colors of the site. (#475)
